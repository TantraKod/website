## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/TantraKodHQ/website.git
```

Go into the project

```bash
cd website
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
